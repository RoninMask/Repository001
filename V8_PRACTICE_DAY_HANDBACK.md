## What is built

| Piece | What it does | Where |
|---|---|---|
| **Local LLM lane** | `ModelWriter` has a backend: `anthropic` (cloud, key) or `ollama` (local, `http://127.0.0.1:11434/api/chat`, no key, `keep_alive` so the model stays resident). Same checker, cache, stamps and fallback for both by construction. `--writer local` runs it alone; `--local` turns it on inside the hybrid; `--local-model` overrides the name. | `ModelWriter(section="local")`, config `v3.local` |
| **Hybrid lanes** | The blob's `licence.lane` picks the writer: fast → local, slow → cloud (config `v3.hybrid.fast_lane / slow_lane`); a lane whose writer is absent (no key, no `--local`) falls to the other model writer, then the template. The manifest's `writer_summary` carries `lanes`, `routed`, and a `cloud` / `local` block each. | `HybridWriter` |
| **`--writer-check`** | One tiny request down each lane, green/yellow/red like the audio check: key present and answering; Ollama up, model pulled, cold and warm latency. Menu **8**. | `writer_check()` |
| **Passages** | On the slow lane a story beat is written as a **LEAD/ANALYST exchange**, one sentence per line, tagged. Sentence budget by race state (`v3.blob.sentences_*`): grid/formation 6, race lull 6, safety car 4, green 3; the fast lane is always 1. Each sentence is **checked on its own**; the passage is cut at its first bad sentence; the first sentence failing is a full fallback. The booth airs sentence one as the line and queues the rest as **continuation claims** (one clip each, `writer: passage`, 0.4 s handover gap): a higher-priority call (a pass, a penalty, an incident) **cuts in at the sentence boundary** and the passage resumes; a tail that waits more than `passage_max_wait_s` (6 s) past the previous sentence, or that the race state no longer allows, is dropped with the rest of its passage (`passage_stale` / `passage_cut`). Line records carry `passage: {id, index, of}`. | `ModelWriter._parse_passage`, `_accept_or_fallback`, `V3Booth._air`, `_validate_continuation` |
| **Passage prompt** | `hoover_prompts_v3.json` → `hoover-v8-passage-1.0`: a `system_passage` prompt (two minds on one subject, call → why → what it means → what next, each line complete because the passage may be cut) used only for passages; the one-line system prompt is unchanged, so fast-lane lines are written exactly as before. The user message names the camera subject when the beat is off screen. | `hoover_prompts_v3.json` |
| **Start programme** | *Expectations:* SF-02 opens on every human on the formation lap with grid notes ("Kannedy starts third", "the race is five laps", "two of our drivers are in this race"), so the slow-lane writer has the whole picture while the field is still rolling. *Silence:* from the first start light (`start_sequence`) the queue is cleared (`drop: lights`), any clip still playing is **hushed** (`SpeechChannel.hush()`), and the channel is freed so the lights-out call airs the instant LGOT arrives. *Lap-one ledger:* SF-04 now owes every human a line in one ANALYST passage: places gained or lost, contact (with whom) or off or clean, retired; the template fallback names the biggest mover. *Tether:* the human premium in the camera's participation multiplier and in the story scores is eased in from 0.5 on the first racing lap to 1.0 by lap ceil(0.5 × total) — lap three of five — so the start belongs to the leaders and the run to turn one, and the broadcast is drawn onto the humans by halfway. Interrupt rows (contact, off, retirement) are never tethered. | `P_SF_02`, `P_SF_04`, `V3Booth._lights`, `human_tether()`, config `v3.tether` |
| **Driver-left** | Participation latch: a car seen human is `was_human`; a human→AI flip sets `left_t`. REL-02 then says one honest line ("lost from the session"), must-call, and never a crash. The live flag still flips, so the human set is honest everywhere at once. The second trigger (a human retiring with no contact) was already REL-02. | `Car.was_human / left_t`, `P_REL_02` |
| **Finish reads penalties** | Time penalties (PENA type 4) accumulate per car; the WINNER claim carries `pending_penalty_s` and whether it costs the win against the gap to second; three new WINNER variants ("crosses the line first, but that five-second penalty is still to be applied, and it costs him the win"). Only added to the claim when a penalty is pending, so a clean finish stays byte-identical to V3. | `RaceModel.pending_penalty_s`, `hoover_words_v4.json` |
| **Duration model refit** | From Mike's run 2 (76 ElevenLabs flash lines, r² 0.92): 3.85 words/s, 0.258 s/word, overhead ≈ 0. `booth.speech_rate_wps` 2.92 → 3.85 in the V4 config (the V3 config stays frozen). The old pair reserved about half a second to a second a line the voice never used. | `hoover_config_v4.json` |
| **Roster V2** | Spoken names stay the gamertag-derived forms from the naming rules (Ronin, Pure, Valor, Faze, Raider); real-name association is a later project. The duplicate race number 2 cleared to null (it matched whichever loaded last). **Real numbers to be filled in before the race.** | `hoover_roster_league.json` |
| **Abu Dhabi** | Corner table with landmark names (the North Hairpin, the chicane at the end of the back straight, Marsa Corner, the hotel section, the final corner), DRS zones, and **estimated** distances from the 2021 layout, flagged `estimated: true` so names resolve from race one; `tests/calibrate_track.py` on the first capture replaces them. | `hoover_tracks.json`, `TrackReference.corner_at` |
| **Camera measure** | `manifest.camera_v8`: realised human share from the cuts' hold times, seconds on humans, longest run away, runs over `away_max_s`. The share-band controller (0.55–0.80 by human count, away max 12 s) was already there; the 08 OCT 42% was the identity failure, not the controller. | `_camera_share()` |
| **Local TTS, once** | `--tts-test local` (menu **L**): one sentence synthesised by the Windows speech engine (System.Speech via PowerShell, nothing to install) to a 24 kHz WAV, played down the cable and the monitor through the same device path the race uses. Proves the local speech path exists. Not used on air; Kokoro wiring is a later conversation. | `tts_test_local()` |
| **Wording backstop** | Story layer only: "one laps" → "one lap" (and places/seconds/…); a lower-case sentence start after a full stop is capitalised. The V3 path is untouched. | `_tidy_line()` |
| **Cuts label** | `method` is `live` when the source and actuation are live, `advisory` otherwise (it was hard-coded `advisory`). | `V3Gallery._cut` |
| **Launcher** | Menu: 8 writer check · 9 start live hybrid (cloud + local, speech, `--log-blobs`, night label asked) · L local voice test · R real-pace hybrid replay with speech. | `Start Hoover.bat` |

## Not proven here — the morning list (in the run card)

1. **A real model line.** No key and no Ollama in this session: the passage prompt has never produced a real exchange. Menu 8 then menu R is the gate; the fail-safe is template.
2. **Ollama's response shape** is from its documented `/api/chat` (non-streaming `message.content`); verified against a stub only.
3. **`hush()`** calls `sounddevice.stop()` and aborts the monitor stream; never run on real PortAudio.
4. **The Windows voice test** runs PowerShell + System.Speech; never run (no Windows here).
5. **Cloud latency for passages**: a six-sentence passage is ~300 tokens; `slow_lane_min_s` was raised 2.5 → 4.0 so a passage is only attempted with at least four seconds to the deadline. If the morning replay shows passages falling back `timeout`, lower `sentences_green` to 2 or raise `slow_lane_min_s`.
6. **Abu Dhabi distances are estimates** until `calibrate_track.py` runs on the first capture.

## Decisions taken without asking

- `slow_lane_min_s` 2.5 → 4.0 (passages need the time).
- The tether is off when the config has no `v3.tether` block (the frozen V3 config), on in V4's.
- Interrupt rows are exempt from the tether (a human in trouble on lap one is the first thing said).
- The local lane defaults to `llama3.2` (what is pulled); `llama3.1:8b` is a one-line config change if the card has the memory.
