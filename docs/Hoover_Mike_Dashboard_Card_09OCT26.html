The Hoover Dashboard

Hoover in your browser: the pre-race checks, start and stop, and the race as it airs. No more typing commands.

What it is. A page that opens in your web browser and runs Hoover for you. It checks the PC before a race, listens to the game to see who is in the lobby, starts the session you pick, and shows the running order, every line as it airs and every camera cut. It runs on your PC only: nothing goes on the internet, and nobody else can see it.

It sits in your Hoover folder next to the tool, and every git pull updates both. It never changes the tool: if the page ever misbehaves, Hoover still runs from the console or Start Hoover.bat exactly as before.

1Get it (once)

PowerShell, in your Hoover folder (D:\Repository001):

git stash
git fetch origin
git checkout claude/v4-state-blob
git pull
python T11_F125_Baby_Hoover_V4_05OCT26.py --version

The first line it prints should read like this (c656d82 or a newer commit):

Baby Hoover V5 (build 09OCT26, script 5.0.0) · claude/v4-state-blob @ c656d82

git stash keeps your local edits safe, as before. If git checkout refuses, send Dustin the message it prints. Do not force it.

2Make the desktop icon (once)

In File Explorer, open your Hoover folder and double-click Make dashboard shortcut (with file extensions hidden, Windows lists it as a Windows Batch File). A black window says it made the shortcut; press any key. A Hoover Dashboard icon is now on your desktop.

3Open it

Double-click Hoover Dashboard. A black window opens, then your browser shows the dashboard at http://127.0.0.1:8777.

Leave the black window open the whole time. It is the dashboard: closing it shuts the dashboard down, and closing it during a race can lose that race's files. The chip at the top of the page reads Connected to Hoover dashboard while all is well. If it turns red, the black window was closed: double-click the icon again.

Down the left side are five pages, and a console sits along the bottom of every page:

Pre-flight · checks before a race Session · pick and start Live · the race as it airs Runs · past sessions This Hoover · version, updates

The console shows everything Hoover prints, the same text as the old black window. When a tool asks a question (Pick devices, Audio check), type the answer in the box at the bottom and press Enter.

4Sound, once per PC (and after any audio change)

On Pre-flight, press Pick devices: type the number for the cable, then for your speakers, in the box at the bottom. Then press Audio check with OBS not recording, and answer y if you heard the beep. Four green lines in the console = good.

5Before every race: Pre-flight

Press Run checks. Each line is green (good), yellow (works, but read the grey line under it) or red (fix before the race; the grey line says how).

LineWhat it checks
This Hoover · GitWhich build this is, and whether anything in the folder was edited by hand
Data filesThe files that sit beside the tool all load
Audio packages · devicesSpeech can run; your cable and speakers are picked (step 4)
Speech key · Model keyThe ElevenLabs and Anthropic keys are set. The model key is needed for the hybrid writer
League rosterEach driver's race number is unique. Yellow is normal tonight; leave the roster off
UDP port 20777Nothing else (another Hoover, a recorder) is holding the telemetry port

Then, with the game in the lobby or a session and you spectating, press Listen to the game. In ten seconds it lists every driver as the game sends them: name, race number, whether show online names is on, and whether their telemetry is public.

Red on Names means some drivers come through as "Player". That is the driver's own game setting, not Hoover. Ask them to turn on Show online names and set Your telemetry to Public, then listen again. If they can't, Hoover still runs and calls them "the car running fifth".

6Run the session

On Session, pick a starting point. For tonight's races use Race: live, HYBRID writer. If the model key is not set, use Race: live, speech on. Check the Tonight block: night label practice, night id today's date. The Command box shows exactly what will run. Start the session once the game is in it and you are spectating, then press Start session. The page jumps to Live: running order (the camera's car marked), lines as they air, spoken / failed, and the share of camera time on humans.

Stop with the red Stop and finalise button. Never stop by closing the black window or the browser in the middle of a race. Stop writes the script, the manifest and tonight's results; it takes a few seconds. Force stop appears only if Stop does nothing after 20 seconds, and it does not save the run. One session at a time: stop one before starting the next.

7After the race

Runs lists each session folder with spoken / failed. Open shows the folder: zip it without the .bin and send it as usual. Replay loads that race's capture on the Session page.

Updates: from standby (no race running), go to This Hoover and press Get latest. The page picks up the new build and any new options by itself.
